# Synthetic scenario format v1

Open a file from **Scenarios → Open JSON file**. Start with [the two-aircraft example](civil-training.json). Successful loading switches the simulator to the new scenario at time zero and pauses it. **Play** starts it, **Step** manually advances one tick, and **Reset** restores the current scenario's initial coordinates. **Load built-in scenario** restores the original three civil aircraft.

Files are UTF-8 JSON, limited to 256 KiB and 1–256 aircraft. Root metadata declares the format, version and synthetic source. IDs are positive and unique within the scenario. The loader trims names and labels, limits their length to 80 and 64 UTF-16 code units respectively, and rejects inline control and format characters. It rejects unknown fields and invalid numeric values. The magnitude of the local horizontal velocity is limited to 2 km/s. The [JSON Schema](scenario-v1.schema.json) describes interchange structure and per-field bounds. The desktop enforces an equivalent typed contract plus the loader-specific limits.

Coordinates are east and north in kilometers, velocities are east and north in kilometers per second, and altitude is meters above the simulation reference plane. The horizontal position bounds apply to initial state. The fixed 40 km radar scope may leave some valid tracks beyond the visible rings. The air traffic list remains available for selection. The model uses constant-velocity planar motion with a fixed desktop tick. Weather, geodetic positions and physical flight profiles require future format versions.
